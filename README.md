## 🗣️ About

This repository contains my solutions for the **C++ Modules 05 to 09** of the 42 Cursus. These modules cover advanced C++ concepts, moving into the Standard Template Library (STL) and templates.

## 📚 Modules Overview

### [Module 05: Repetition and Exceptions](./Module05/README.md)

**Focus:** Exceptions, Try/Catch blocks.

> Introduces C++ exceptions for robust error handling.
>
> [Read more](./Module05/README.md)

---

### [Module 06: C++ Casts](./Module06/README.md)

**Focus:** C++ Casts, Scalar conversion, Serialization.

> Covers the different types of casts in C++ (`static_cast`, `dynamic_cast`, `reinterpret_cast`, `const_cast`) and serialization.
>
> [Read more](./Module06/README.md)

---

### [Module 07: C++ Templates](./Module07/README.md)

**Focus:** Templates.

> Introduces templates for creating generic functions and classes.
>
> [Read more](./Module07/README.md)

---

### [Module 08: Templated containers, iterators, algorithms](./Module08/README.md)

**Focus:** STL Containers, Iterators, Algorithms.

> Focuses on the usage of standard containers (vector, list, map, etc.) and algorithms.
>
> [Read more](./Module08/README.md)

---

### [Module 09: STL](./Module09/README.md)

>
> [Read more](./Module09/README.md)

## 🛠️ Usage

Each exercise can be compiled individually. Navigate to the exercise directory and run `make`.

```bash
cd ModuleXX/exYY
make
./program_name
```
